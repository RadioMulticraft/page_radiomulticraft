📰 News-Editor

Starnews für Radio Multicraft bearbeiten – ganz ohne Code.

So funktioniert's:
  1. Unten auf „news.json laden" klicken und die aktuelle news.json von deinem Server auswählen (optional – ohne das startest du mit einer leeren Liste).
  2. Meldungen bearbeiten, neue hinzufügen, alte entfernen oder die Reihenfolge mit ▲ ▼ ändern.
  3. Unten auf „news.json herunterladen" klicken.
  4. Die heruntergeladene Datei per FTP/Hosting-Panel hochladen und die alte news.json im selben Ordner wie index.html damit ersetzen.
Die Website selbst musst du dafür nie mehr anfassen – sie liest die Meldungen automatisch aus news.json.
